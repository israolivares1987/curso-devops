Para convertir esta guía a PDF, puedes usar:

```bash
pandoc README.md lengua-literatura/*.md matematica/*.md ciencias/*.md historia/*.md ingles/*.md recursos/*.md -o guia-completa-8basico.pdf --toc
```

3. Genera PDF automáticamente
